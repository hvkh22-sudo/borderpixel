# App review notes (draft)

- No login required. All core features work offline except AI Script Studio.
- Camera/microphone are requested when opening the camera; speech recognition when Voice Follow or
  captions are first used. Purpose strings are in Info.plist / permission dialogs.
- The teleprompter overlay is not recorded into the video.
- Subscriptions: Pro Monthly, Pro Annual (auto-renewing), Lifetime (non-consumable), AI credit pack
  (consumable). Restore Purchases is on the paywall.
- Test steps: Home › Try a sample script › Open camera › Record › Stop › Add captions › Export.
